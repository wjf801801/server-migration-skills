# 实战案例复盘：w3 与 5p 双主力主机向 865 整合迁移

> **项目背景**：将原物理部署在 **w3（AMD 7840H, x86_64）** 与 **5p（香橙派 5 Plus, RK3588, aarch64）** 上的全部家庭基础设施、投研量化体系、媒体影音、出站打洞隧道整合迁移至单台 **865（高通骁龙 865 工控微型机, SM8250, 16GB RAM, aarch64）**。

---

## 一、 硬件与架构演进

| 机器 | 原角色 | CPU 架构 | 内存 | 最终处置 |
| :--- | :--- | :--- | :--- | :--- |
| **w3** | 原主力应用与分流机（192.168.2.133） | x86_64 (AMD 7840H) | 32 GB | 下线常驻服务，切为 DHCP（192.168.2.61）作为重型计算备用机 |
| **5p** | 原量化与媒体中枢（192.168.2.151） | aarch64 (RK3588) | 8 GB | 下线常驻服务，切为 DHCP（192.168.2.50）安全关机冷备 |
| **865** | 新一代常驻低功耗微型服务器 | aarch64 (SM8250) | 16 GB | **单机承载全量服务**，同时持有 `192.168.2.133` 与 `192.168.2.151` |

---

## 二、 关键技术决策

### 1. 方案 A（统合单 IP 换端口） vs 方案 B（辅助 IP 接管原 IP）
- **否决方案 A**：如果把 5p 服务全改成 865 的 `.133`，且同号端口改别名，需要逐一修改客厅电视盒、卧室中控 Pad、手机 App、电脑自动化脚本等数十个客户端配置，极易造成遗漏且后续维护心智负担重。
- **采纳方案 B**：利用 Linux 多 IP 机制，865 在网卡上挂载 `192.168.2.151/32`，保留全部历史访问入口。对局域网和外网而言，物理机虽变，但入口网络行为零变化。

### 2. 端口重叠冲突治理（8146 与 8150）
- **现象**：w3 有 `report-hub` (8146) 和 `workbench` (8150)；5p 有 `sell-guard` (8146) 和 `musicweb` (8150)。
- **治理**：
  - 开启 Linux 内核参数 `net.ipv4.ip_nonlocal_bind = 1`；
  - `report-hub` 与 `workbench` 严格监听 `192.168.2.133:<port>`；
  - `sell-guard` 与 `musicweb` 严格监听 `192.168.2.151:<port>`；
  - 端口 8098 冲突通过将无外部调用的 `doubao-chat` 移至 8087，释放 8098 独占给 `music-dl`。

### 3. Python 运行时版本代差治理
- 865 基础系统为 Ubuntu 24.04 (Python 3.12)，而 5p 量化体系依赖 Python 3.10 编译好的 C 扩展（Pandas、Numpy、Cython 模块）；
- 通过 `uv` 在 865 上构建安装独立系统级 `python3.10.22`，虚拟环境重新符号链接至新解释器，无痛复活历史量化系统。

---

## 三、 出站穿透与域名迁移实录

在关闭 5p 前，重点接管两项出站能力：
1. **Cloudflare Zero Trust 远程隧道（`cloudflared`）**：
   - 提取原 Token，在 865 安装官方 deb 包并注册 systemd 服务；
   - 启动后自动同步 Ingress 表，无缝接回 `av`、`iptv`、`pan`、`stock`、`radar` 等 18 个外网子域名。
2. **反向 SSH 隧道（`home-tunnel`）**：
   - 将 `id_tunnel` 部署至 865，连接美国 rn (66.63.177.132:5522) 与国内 cn (212.103.62.101:22)；
   - 穿透回 865 本地 22 端口，恢复 12251 打洞监听，解除看门狗警报。

---

## 四、 成果与资源表现

- **服务接管**：共 9 个 Docker 容器 + 30+ Systemd 服务 + 20+ Crontab 任务；
- **资源开销**：865 运行全量业务后，物理内存占用仅 **2.5 GB / 15 GB**（可用 12.5 GB），存储剩余 **85 GB**，Load average **0.38**，核心温度稳定在 **33~36℃**；
- **整机收益**：下线了两台功耗合计约 30~50W 的老物理机，单机功耗降至约 3~5W，安静无噪音，实现全家常驻服务的大一统。
